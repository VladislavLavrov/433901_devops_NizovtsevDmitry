## Обновление

Используйте отдельную ветку kafka согласно пособию. Этот архив содержит ПОЛНУЮ замену исходников. В локальном проекте сначала сохраните копию текущей версии за пределами репозитория. Уберите из проекта прежние папки Controllers, Models, Services, Views, Data, Migrations (они целиком есть в архиве), затем скопируйте файлы архива в корень с заменой. .git и .env не удаляйте. Это нужно, чтобы не остались прежние Result.cshtml, KafkaOptions.cs и другие исключённые дополнения. Если делали собственные изменения, сохраните их в резервной копии.

```bash
git add -A
git commit -m "Use methodical Kafka producer consumer callback and topic nizovtsev"
git push
```

В PuTTY из вашей папки репозитория, на той же ветке:

```bash
git pull --ff-only
sudo docker rm -f nizovtsev13-kafka-ui nizovtsev13-kafka-init nizovtsev13-kafka
sudo docker compose up -d --build
sudo docker compose ps
sudo docker compose logs --tail=80 web
```

Команда rm удаляет только наши собственные прежние Kafka-контейнеры. MariaDB и её том сохраняются. .env не перезаписывайте, пароли ПР2 не меняйте. Если старые контейнеры отсутствуют, сообщение No such container пропустите. Не применяйте down -v.
